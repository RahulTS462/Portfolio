# Rahul T Sathyan — Portfolio

Static site, no build step.

- `index.html` — the whole site (HTML, CSS, JS inline)
- `Rahul_Sep_26.pdf` — CV behind the "Download CV" buttons

Open `index.html` in a browser, or upload both files to any static host
(GitHub Pages, Netlify, Cloudflare Pages, S3).

To add a project, copy an `<article class="proj">` block in the Projects section.
Update the placeholder GitHub link in that block to the exact repository URL.
